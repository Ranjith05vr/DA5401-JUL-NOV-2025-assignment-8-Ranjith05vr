# DA5401 Assignment 8: Ensemble Learning on Bike Sharing Data
Name ; Ranjith V R
## Objective
This project implements and compares three major **ensemble learning** techniques:
1. **Bagging Regressor** – to reduce model variance  
2. **Gradient Boosting Regressor** – to reduce model bias  
3. **Stacking Regressor** – to combine diverse models for optimal bias–variance trade-off  

The task is to predict **bike rental counts (cnt)** from the **Bike Sharing Hourly dataset** using regression-based ensemble methods.
